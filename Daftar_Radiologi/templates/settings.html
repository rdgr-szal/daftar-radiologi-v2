Panduan Pematuhan Data Pesakit & Syarat Storan

1. Pematuhan Keselamatan Maklumat Sektor Awam: Rekod Pesakit & Maklumat Peribadi (PII) dikategorikan sebagai Data Terkawal mengikut Arahan Keselamatan & GP ICT KKM.
• Pangkalan data yang dibenarkan: MyGovCloud@PDSA, On-Premise Kerajaan, Local Intranet SQLite / Postgres / MySQL.
• Amaran: Public Cloud luar negara (contoh: Cloudflare D1, Supabase Awam) adalah TIDAK DIBENARKAN.
2. Strategi Ketahanan Data 3-layer (Triple Redundancy): • Primary storage (Excel .xlsx): Dijana & disimpan terus ke local storage (synchronous disk write) sebaik sahaja didaftarkan mengikut format piawai audit PER.SS-RA 101.

• Secondary storage (DataBase): Sangat digalakkan sebagai second layer backup (SQLite Intranet NAS, MyGovCloud@PDSA, atau On-Premise) untuk carian pantas & pemeliharaan rekod.

• Third storage (Auto-Backup .zip file): Fungsi keselamatan sedia ada secara automatik dalam bentuk fail zip (.zip) yang boleh sync pada Google Drive Desktop (Akaun MyGovUC).

Panduan Database (Setup Help)

Dokumentasi teknikal, pematuhan keselamatan KKM, dan konfigurasi pelayan

1. Pematuhan Keselamatan Maklumat Sektor Awam (KKM)

Rekod Perubatan Pesakit & Personally Identifiable Information (PII) dikategorikan sebagai RASMI: Data Terkawal. Penggunaan Public Cloud luar negara (Off-shore CSP) adalah TIDAK DIBENARKAN.

Database Storage Yang Disyorkan:
  1. MyGovCloud@PDSA: Managed PostgreSQL / MySQL di data centre sektor awam Malaysia.
  2. Server Intranet On-Premise: PostgreSQL / MySQL di local server Hospital / PKD.
  3. Local SQLite / NAS: local database atau Shared Drive intranet.
2. Panduan Database Setup
SQLite (Local / Intranet Network Drive) Recommended untuk KK

Sesuai untuk Klinik Kesihatan atau kaunter bersaiz kecil/sederhana. Tiada pemasangan pelayan rumit diperlukan.

  1. Pilih SQLite Local / Intranet Drive pada menu Tetapan.
  2. Untuk fail tempatan, kekalkan radiologi_local.db (tersimpan di folder Pendaftaran/).
  3. Untuk share directory (NAS / Shared Drive), masukkan directory cth: Z:\Radiologi\radiologi_Data\radiologi_local.db.
  4. Klik "Create Database" untuk create tables secara automatik.
PostgreSQL / MyGovCloud@PDSA Recommended untuk Hospital

Contoh arahan bagi Pentadbir Sistem (DBA) di pelayan PostgreSQL: 

CREATE DATABASE radiologi_db;
CREATE USER rad_user WITH PASSWORD 'KataLaluanSelamat123';
GRANT ALL PRIVILEGES ON DATABASE radiologi_db TO rad_user;
Parameter Tetapan: Host: 10.x.x.x | Port: 5432 | Database: radiologi_db
MySQL / MariaDB (Intranet Server) Intranet Server 
CREATE DATABASE radiologi_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'rad_user'@'%' IDENTIFIED BY 'KataLaluanSelamat123';
GRANT ALL PRIVILEGES ON radiologi_db.* TO 'rad_user'@'%';
Parameter Tetapan: Host: 192.168.x.x | Port: 3306 | Database: radiologi_db
3. Cara Semak Host IP Server (IP Address)
Windows System:

  2. Taip arahan: ipconfig
  3. Cari nilai IPv4 Address.
Linux / Mac System:
  1. Buka Terminal.
  2. Taip arahan: ip a / ifconfig
  3. Use IP Static from IT Hospital.
4. Sync & PC Migration

Aplikasi ini menyimpan rekod ke fail Excel (.xlsx) tempatan secara serta-merta (synchronous disk write) selepas butang DAFTAR ditekan. Ini memastikan data yang didaftarkan kekal selamat pada hard disk sebelum sync dijalankan. Jika secondary database disconnected, rekod disimpan dalam queue dan boleh sync semula menggunakan Sync Pending Data.

* Migrate ke PC baharu, install aplikasi dan gunakan "Restore Data from Backup File (.zip)" untuk mengembalikan seluruh sistem.
