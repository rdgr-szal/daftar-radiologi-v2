Data Compliance Guide for Patient Records & Storage Conditions

1. Public Sector Information Security Compliance: Patient records & personal information (PII) are classified as Controlled Data according to Security Directive & GP ICT KKM.
• Allowed databases: MyGovCloud@PDSA, Government on-premise, local intranet SQLite / Postgres / MySQL.
• Warning: Foreign public clouds (e.g., Cloudflare D1, public Supabase) are NOT PERMITTED.
2. 3-Layer Data Resilience Strategy (Triple Redundancy): • Primary storage (Excel .xlsx): Generated and saved directly to local storage (synchronous disk write) as soon as registered per PER.SS-RA 101 audit format.

• Secondary storage (Database): Strongly recommended as a second-layer backup (SQLite intranet NAS, MyGovCloud@PDSA, or on-premise) for fast queries and record preservation.

• Third storage (Auto-Backup .zip): Built-in security creates zip files automatically that can sync to Google Drive Desktop (MyGovUC account).

Database Setup Guide)

Teknikal documentation, KKM security compliance, dan server configuration

1. Public Sector Information Security Compliance (KKM)

Patient Medical Records & Personally Identifiable Information (PII) are categorized as OFFICIAL: Controlled Data. Use of offshore Public Cloud Service Providers (CSPs) is NOT ALLOWED.

Recommended Database Storage:
  1. MyGovCloud@PDSA: Managed PostgreSQL / MySQL at Malaysian public sector data centres.
  2. Server Intranet On-Premise: PostgreSQL / MySQL on Hospital / PKD local server.
  3. Local SQLite / NAS: local database or Shared Drive intranet.
2. Panduan Database Setup
SQLite (Local / Intranet Network Drive) Recommended untuk KK

Ideal for Health Clinics or small/medium-sized counters. No complex server installation required.

  1. Select SQLite Local / Intranet Drive in the Settings menu.
  2. For local files, keep radiologi_local.db (stored in Pendaftaran/ folder).
  3. For shared directories (NAS / Shared Drive), enter the directory, e.g.: Z:\Radiologi\radiologi_Data\radiologi_local.db.
  4. Click "Create Database" to create tables automatically.
PostgreSQL / MyGovCloud@PDSA Recommended untuk Hospital

Sample commands for System Administrator (DBA) on PostgreSQL server: 

CREATE DATABASE radiologi_db;
CREATE USER rad_user WITH PASSWORD 'KataLaluanSelamat123';
GRANT ALL PRIVILEGES ON DATABASE radiologi_db TO rad_user;
Parameter Tetapan: Host: 10.x.x.x | Port: 5432 | Database: radiologi_db
MySQL / MariaDB (Intranet Server) Intranet Server 
CREATE DATABASE radiologi_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'rad_user'@'%' IDENTIFIED BY 'KataLaluanSelamat123';
GRANT ALL PRIVILEGES ON radiologi_db.* TO 'rad_user'@'%';
Parameter Tetapan: Host: 192.168.x.x | Port: 3306 | Database: radiologi_db
3. Cara Semak Host IP Server (IP Address)
Windows System:
  1. Press Win + R, type cmd.
  2. Type command: ipconfig
  3. Look for IPv4 Address value.
Linux / Mac System:
  1. Open Terminal.
  2. Type command: ip a / ifconfig
  3. Use IP Static from IT Hospital.
4. Data Synchronization & PC Migration

This application stores records to a local Excel file (.xlsx) immediately (synchronous disk write) after the REGISTER button is pressed. This ensures registered data remains safe on the hard disk before sync runs. If the secondary database is disconnected, the record is stored in a queue and can be synced again using Sync Pending Data.

* Migrate to a new PC, install the application and use "Restore Data from Backup File (.zip)" to restore the entire system.
