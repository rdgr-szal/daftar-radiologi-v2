Selamat datang ke **Sistem Daftar Radiologi**. Ini panduan ringkas untuk *install* dan jalankan aplikasi di PC klinik anda.

---

## 🚀 1. Cara Install (1-Click Setup)

*Nota: Aplikasi memerlukan Python 3.10 ke atas. Skrip di bawah akan check dan install secara automatik jika belum ada.*

### 💻 Windows:

1. **Copy** folder project ini ke dalam PC klinik dan buka folder tersebut.
2. **Double-click** fail `Install_Windows.bat`.
3. Skrip akan setup semuanya sendiri. Selesai! *Shortcut* **Daftar Radiologi** akan muncul di Desktop.

### 🍏 macOS:

1. **Double-click** fail `Install_Mac.command` di dalam folder project.
2. Terminal akan terbuka dan berjalan secara automatik. Selesai! *Shortcut* **Daftar Radiologi.command** akan muncul di Desktop.

---

## 🛠️ Troubleshooting

### 🔴 macOS (Error Permission / Unidentified Developer):

* **Fix Permission:** Buka Terminal, taip `chmod +x ` (pastikan ada jarak/space di hujung). **Drag & drop** fail `Install_Mac.command` dari Finder ke dalam Terminal, lalu tekan **Enter**. Cuba *double-click* semula fail tadi.
* **Cara Alternatif:** Buka Terminal, taip `bash `, **drag & drop** fail `Install_Mac.command` ke dalam Terminal, lalu tekan **Enter**.
* **Bypass Sekatan Apple:** Tahan butang **Control** di keyboard, *right-click* fail `Install_Mac.command` -> pilih **Open** -> klik **Open** sekali lagi pada paparan amaran.

### 🔵 Windows (SmartScreen / PowerShell Block):

* **Unblock Fail:** *Right-click* fail `Install_Windows.bat` -> **Properties**. Di tab *General*, tick kotak **Unblock** di bahagian bawah -> Klik **Apply** & **OK**.
* **Bypass Polisi PowerShell:** Buka *Windows PowerShell* (Run as Administrator). Taip command ini dan tekan **Enter**:
`Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process`
Kemudian, *run* semula fail `Install_Windows.bat`.

---

## ⚙️ 2. First-Time Setup

Bila anda buka aplikasi buat kali pertama, *browser* akan terbuka secara automatik ke halaman Setup. Sila isi info berikut:

1. **Nama Fasiliti:** Masukkan nama penuh klinik (Cth: KK BANDAR BARU SELAYANG).
2. **Singkatan Fasiliti:** Masukkan singkatan pendek (Cth: KKBBS).
3. **Klinik Rujukan:** Taip nama klinik rujukan -> klik **Tambah** (atau tekan Enter).
4. Klik **Start Now**. *(Sistem akan setup database Excel automatik mengikut singkatan klinik anda).*

---

## 📅 3. Daily Usage

Untuk hari-hari seterusnya, prosesnya sangat mudah:

1. Pergi ke Desktop PC anda, **double-click** *shortcut* **Daftar Radiologi**.
2. Biarkan tetingkap hitam (Terminal/CMD) kekal terbuka di latar belakang.
3. *Browser* akan terbuka sendiri dan anda boleh terus mula daftar pesakit!

---

## 🔄 4. Cara Update Aplikasi

1. **Tutup App:** Pastikan aplikasi Daftar Radiologi ditutup terlebih dahulu.
2. **Download Update:** Dapatkan fail `.zip` update terbaru daripada *developer*.
3. **Copy & Paste:** Buka folder `DaftarRadiologi_App` sedia ada di Desktop. Extract fail baru dari zip, kemudian **paste & overwrite** ke dalam folder tersebut.

> ⚠️ **PENTING:** **JANGAN** padam atau ganti folder **`Pendaftaran`**. Folder ini menyimpan semua data rekod pesakit sedia ada anda!

4. **Selesai:** Buka aplikasi seperti biasa menggunakan *shortcut*.

---

## 🧑‍💻 5. Developer Mode

Jika anda mahu *edit code* terus tanpa perlu *compile*:

1. **Activate Virtual Environment (.venv):**
* Windows: `.venv\Scripts\activate`
* macOS: `source .venv/bin/activate`


2. **Run App:**
```bash
cd Daftar_Radiologi
python DaftarRadiologi.py

```

ENGLISH

Welcome to the **Radiology Registration System**. Here is a quick guide to install and run the application on your clinic's PC.

---

## 🚀 1. How to Install (1-Click Setup)

*Note: The application requires Python 3.10 or higher. The script below will automatically check and install it if it is missing.*

### 💻 Windows:

1. **Copy** this project folder to your clinic PC and open the folder.
2. **Double-click** the `Install_Windows.bat` file.
3. The script will set up everything automatically. Done! A **Daftar Radiologi** shortcut will appear on your Desktop.

### 🍏 macOS:

1. **Double-click** the `Install_Mac.command` file inside the project folder.
2. Terminal will open and run the installation automatically. Done! A **Daftar Radiologi.command** shortcut will appear on your Desktop.

---

## 🛠️ Troubleshooting

### 🔴 macOS (Permission Error / Unidentified Developer):

* **Fix Permission:** Open Terminal, type `chmod +x ` (make sure to leave a space at the end). **Drag & drop** the `Install_Mac.command` file from Finder into the Terminal, then press **Enter**. Try double-clicking the file again.
* **Alternative Method:** Open Terminal, type `bash `, **drag & drop** the `Install_Mac.command` file into Terminal, then press **Enter**.
* **Bypass Apple Restrictions:** Hold the **Control** key on your keyboard, **right-click** `Install_Mac.command` -> select **Open** -> click **Open** again on the warning prompt.

### 🔵 Windows (SmartScreen / PowerShell Block):

* **Unblock File:** **Right-click** `Install_Windows.bat` -> **Properties**. Under the *General* tab, check the **Unblock** box at the bottom -> Click **Apply** & **OK**.
* **Bypass PowerShell Policy:** Open *Windows PowerShell* (Run as Administrator). Type this command and press **Enter**:
`Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process`
Then, run the `Install_Windows.bat` file again.

---

## ⚙️ 2. First-Time Setup

When you open the application for the first time, your browser will automatically open to the Setup page. Please fill in the following details:

1. **Facility Name:** Enter the full name of your clinic (e.g., KK BANDAR BARU SELAYANG).
2. **Facility Abbreviation:** Enter a short code/acronym (e.g., KKBBS).
3. **Referral Clinics:** Type the name of the referring clinic -> click **Add** (or press Enter).
4. Click **Start Now**. *(The system will automatically format and rename the Excel database using your clinic's abbreviation).*

---

## 📅 3. Daily Usage

For daily use, the process is very simple:

1. Go to your Desktop, **double-click** the **Daftar Radiologi** shortcut.
2. Keep the black window (Terminal/CMD) open in the background.
3. The browser will open automatically, and you can start registering patients!

---

## 🔄 4. How to Update the App

1. **Close the App:** Make sure the Radiology Registration application is closed.
2. **Download Update:** Get the latest update `.zip` file from the developer.
3. **Copy & Paste:** Open the existing `DaftarRadiologi_App` folder on your Desktop. Extract the new files from the zip, then **paste & overwrite** them into that folder.

> ⚠️ **IMPORTANT:** **DO NOT** delete or replace the **`Pendaftaran`** folder. This folder contains all your existing patient records!

4. **Done:** Open the application as usual using the shortcut.

---

## 🧑‍💻 5. Developer Mode

If you want to edit the code directly without compiling:

1. **Activate Virtual Environment (.venv):**
* Windows: `.venv\Scripts\activate`
* macOS: `source .venv/bin/activate`


2. **Run App:**
```bash
cd Daftar_Radiologi
python DaftarRadiologi.py

```
