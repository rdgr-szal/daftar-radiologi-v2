======================================================================
PANDUAN DEPLOYMENT & PELANCARAN / DEPLOYMENT GUIDE
Sistem Buku Daftar Radiologi KKM (PER.SS-RA 101 V2)
======================================================================

----------------------------------------------------------------------
1. DEPLOYMENT LOKAL (STANDALONE KLINIK PC)
----------------------------------------------------------------------

A. DI WINDOWS PC:
   1. Copy folder projek ini ke dalam PC sasaran.
   2. Dwi-klik fail `Install_Windows.bat`.
   3. Skrip akan memasang persekitaran Python (.venv) dan perpustakaan yang diperlukan.
   4. Icon shortcut "Daftar Radiologi" akan secara automatik dicipta di Desktop.
   5. Untuk penggunaan harian: Dwi-klik shortcut di Desktop.

B. DI MACOS:
   1. Copy folder projek ini ke dalam Mac sasaran.
   2. Dwi-klik fail `Install_Mac.command`.
   3. Jika disekat oleh macOS Security:
      - Buka Terminal dan taip: `chmod +x Install_Mac.command`
      - Atau Right-click `Install_Mac.command` -> Open.
   4. Fail shortcut `.command` akan dicipta di Desktop.

----------------------------------------------------------------------
2. DEPLOYMENT RANGKAIAN LOCAL / LAN (AKSES PELBAGAI DEVICE)
----------------------------------------------------------------------

Jika mahu borang pendaftaran dibuka oleh beberapa komputer/tablet dalam rangkaian (Wi-Fi / LAN) Klinik yang sama:

1. Buka Terminal / Command Prompt pada komputer Server.
2. Dapatkan IP Address Komputer Server:
   - Windows: `ipconfig` (lihat IPv4 Address, contoh: 192.168.1.100)
   - macOS: `ifconfig` atau System Settings -> Network.
3. Jalankan aplikasi Flask:
   - Windows: `.venv\Scripts\activate`
   - macOS: `source .venv/bin/activate`
   - Run: `python Daftar_Radiologi/DaftarRadiologi.py`
4. Komputer atau tablet lain dalam WiFi/LAN yang sama boleh membuka pelayar (Chrome/Edge/Safari) dan taip:
   `http://192.168.1.100:5000` (Gantikan IP mengikut IP Komputer Server anda).

----------------------------------------------------------------------
3. PENGURUSAN DATABASE & BACKUP DATA EXCEL
----------------------------------------------------------------------

1. Lokasi Data:
   - Semua rekod disimpan di dalam folder: `Pendaftaran/`
   - Format fail: `BUKU DAFTAR XRAY {Tahun}.xlsx` (Satu fail Excel untuk setahun, dengan 12 sheet bulanan JAN-DIS).
   - Konfigurasi Klinik: `Pendaftaran/config.json`

2. Backup Data Harian / Bulanan:
   - Cuma perlu buat salinan (copy) fail `BUKU DAFTAR XRAY {Tahun}.xlsx` dari folder `Pendaftaran/` ke External Harddisk / USB Drive / Cloud Backup Klinik.

----------------------------------------------------------------------
4. CARA UPDATE VERSI APLIKASI
----------------------------------------------------------------------

1. Tutup aplikasi yang sedang berjalan.
2. Dapatkan fail kemaskini (update) baharu.
3. Salin dan timpa (overwrite) kod baharu ke dalam folder aplikasi.
4. AMARAN: JANGAN PADAM ATAU TIMPA FOLDER `Pendaftaran/` kerana di situ terletaknya data pesakit sedia ada.

----------------------------------------------------------------------
5. MANUAL RUN (DEVELOPER / MAINTENANCE)
----------------------------------------------------------------------

Windows:
  .venv\Scripts\activate
  cd Daftar_Radiologi
  python DaftarRadiologi.py

macOS / Linux:
  source .venv/bin/activate
  cd Daftar_Radiologi
  python3 DaftarRadiologi.py
