========================================================================
PANDUAN KEMAS KINI (UPDATE) - DAFTAR RADIOLOGI
========================================================================

Dokumen ini menerangkan cara untuk mengemas kini (update) UI/graf/halaman 
aplikasi Daftar Radiologi tanpa mengganggu atau memadam pangkalan data 
(folder "Pendaftaran") sedia ada milik pengguna.

------------------------------------------------------------------------
BAHAGIAN 1: CARA UPDATE UNTUK DEVELOPER (PEMBANGUN)
------------------------------------------------------------------------
Lakukan langkah ini di komputer pembangun sebelum mengedarkan fail:

1. Kemas Kini UI/Kod:
   - Buat perubahan reka bentuk pada folder "templates" (HTML) atau "static" (CSS/JS).
   - Edit "DaftarRadiologi.py" jika ada penambahan fungsi atau API baharu.

2. Compile Semula Aplikasi:
   - Jalankan "Install_Mac.command" (Mac) or "Install_Windows.bat" (Windows)
     di komputer anda.
   - Skrip ini akan menghasilkan folder "DaftarRadiologi_App" baharu di Desktop anda.

3. Sediakan Pakej Update untuk Pengguna:
   - Buka folder "DaftarRadiologi_App" yang baru dicompile di Desktop anda.
   - PADAM folder "Pendaftaran" di dalam folder tersebut (untuk mengelakkan data pengguna teroverwrite).
   - Zipkan keseluruhan folder "DaftarRadiologi_App" yang tinggal (mengandungi fail executable, templates, dan static).
   - Hantar fail zip tersebut kepada pengguna.


------------------------------------------------------------------------
BAHAGIAN 2: CARA UPDATE UNTUK USER (PENGGUNA)
------------------------------------------------------------------------
Langkah yang perlu dilakukan oleh pengguna pada komputer mereka:

1. Tutup Aplikasi:
   - Pastikan aplikasi Daftar Radiologi ditutup terlebih dahulu.

2. Dapatkan Fail Update:
   - Muat turun/terima fail zip update yang dihantar oleh pembangun.

3. Gantikan Fail UI/Program:
   - Buka folder "DaftarRadiologi_App" sedia ada di Desktop anda.
   - Ekstrak/salin (copy) fail-fail baharu daripada fail zip update.
   - Gantikan (paste & overwrite) fail/folder lama dalam folder "DaftarRadiologi_App" anda.
   
   ⚠️ PENTING:
   - JANGAN PADAM ATAU GANTIKAN folder "Pendaftaran" sedia ada anda.
   - Folder "Pendaftaran" mengandungi semua data rekod pesakit anda.

4. Selesai:
   - Buka aplikasi menggunakan shortcut seperti biasa. UI baharu sedia digunakan.
